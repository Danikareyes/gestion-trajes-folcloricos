# gestion-trajes-folcloricos
Plataforma web para la promoción y gestión de trajes folclóricos ecuatorianos, accesorios culturales y vestimenta de gala. Incluye catálogo digital, administración de inventario, reservas y difusión de servicios para eventos y presentaciones artísticas.

## Objetivo
 
Facilitar la gestión de inventario, reservas y difusión de los servicios ofrecidos por un emprendimiento dedicado al alquiler y comercialización de trajes tradicionales para eventos culturales, educativos y artísticos.
 
## Características principales
 
- Catálogo de trajes por región cultural.
- Gestión de inventario.
- Galería de fotografías.
- Información de servicios de danza y eventos.
- Gestión de reservas.
- Administración de categorías y productos.
- Diseño responsivo para dispositivos móviles y escritorio.
